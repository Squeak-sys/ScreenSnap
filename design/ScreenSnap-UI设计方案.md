# ScreenSnap 2.0 · UI 设计方案

> 设计语言代号：**SHUTTER（取景器）**
> 定位：**专业工具的克制 + 取景器的仪式感** —— 以 Windows 11 Fluent 为骨架，用取景框角标、快门蓝与胶片隐喻建立 ScreenSnap 自己的记忆点，同时保持系统原生窗口般的习惯感。
> 配套高保真原型：`design/prototype.html`（可交互，含 ① 截图编辑器 ② 历史库 ③ 设置 ④ 设计规范 四个视图）

---

## 1. 设计上下文

| 维度 | 结论 |
|---|---|
| 目标用户 | 中文 Windows 个人用户；已被 QQ/微信截图、Snipaste 训练出固定操作习惯 |
| 核心场景 | 热键唤起 → 框选 → （调整选区）→ 标注 → 完成/贴图；低频回溯历史、改配置 |
| 品牌气质 | 轻量、快、可靠；像相机快门一样"一按即得" |
| 技术约束 | Python + Tkinter，无 Web 依赖；须沿用现有 `editor.py` 的 transparentcolor 圆角条带方案与多屏定位补丁 |
| 设计原则 | **习惯优先**：流程、键位（1–6 选工具 / Ctrl+Z / Enter / Esc）、绿色确认红色危险均不变，只升级视觉与反馈 |

## 2. 色彩系统（WCAG AA）

| Token | 值 | 用途 |
|---|---|---|
| `accent` | `#2F6DF6` | 主色·快门蓝：选区边框、选中态、主按钮、链接 |
| `accent-hover` | `#2559D6` | 主按钮悬停 |
| `accent-soft` | `#E8EFFE` | 选中底色、聚焦光环（3px 外圈） |
| `success` | `#0FA958` | 「完成」按钮（沿用现有绿色确认心智，由 #07C160 精调） |
| `danger` | `#E5484D` | 删除、录制红点、关闭钮悬停（沿用现值） |
| `warn` | `#F5A623` | 冲突提示、即将过期 |
| `ink` | `#1C2430` | 一级文本（不用纯黑） |
| `ink-2` | `#5B6472` | 二级文本 |
| `ink-3` | `#9AA2AD` | 占位、状态栏、快捷键角标 |
| `line` | `#E3E6EA` | 分割线、边框 |
| `surface` | `#FFFFFF` | 窗口面板 |
| `surface-2` | `#F7F8FA` | 侧栏、输入底 |
| `surface-3` | `#EEF0F3` | 悬停底 |
| `canvas` | `#F0F1F4` | 页面/工作区底 |

对比度：`ink` on `surface` ≈ 15.2:1；`accent` 白字 ≈ 4.6:1（≥4.5:1 AA 通过）；`ink-2` on `surface` ≈ 6.9:1。
**深色模式**：同结构翻转（`surface #1E242C / canvas #161B22 / ink #E8ECF1`），accent 提亮至 `#6F9BFF` 保证暗底对比，一期可不做、token 预留。

## 3. 字体与层级

- 字体栈：`Microsoft YaHei UI`（Tkinter 主字体），尺寸徽标/数字用 `Segoe UI` 提升锐度；不引入外部字体文件。
- 层级（仅 5 级，防膨胀）：
  1. **窗口/区块标题** 19px / 650 / -0.01em
  2. **条目标题·按钮** 13.5px / 600
  3. **正文·说明** 13.5px / 400（说明文字用 ink-2）
  4. **辅助 Caption** 12px / 400 / ink-3
  5. **尺寸徽标** 12px / 600 / 主色底白字

## 4. 间距 / 圆角 / 阴影

- 间距 4px 基数：`4 / 8 / 16 / 24 / 40`；卡片网格与窗口内边距统一 16/24。
- 圆角：按钮·输入框·卡片 `8px`；窗口·大卡片 `10px`；**悬浮工具条·开关·胶囊徽标 `999px`**（沿用现有胶囊工具条形态）。
- 阴影三级：
  - `card`: `0 1px 2px rgba(20,30,46,.06)`
  - `float`: `0 8px 28px -4px rgba(20,30,46,.24), 0 2px 6px …`（工具条/弹层）
  - `win`: `0 24px 64px -12px rgba(20,30,46,.22) …`（窗口）

## 5. 动效规范

| 场景 | 时长 | 缓动 |
|---|---|---|
| hover / 按下 | 120ms | ease-out（按下附 1px 下沉或 0.88 缩放） |
| 弹层（色板/下拉/Tooltip） | 180–220ms | `cubic-bezier(.16,1,.3,1)` 上浮淡入 |
| Switch 滑块 | 220ms | 同上 |
| 选区拖拽 | **即时，无动画** | 坐标类属性一律不动画化，保证"跟手" |

遵循系统"减少动态效果"设置时关闭过渡。

## 6. 逐界面设计

### 6.1 截图编辑器（最高频路径）
- **选区**：遮罩 `rgba(16,22,32,.46)`；选区主色 2px 描边；**四角取景器角标**（14px L 形、2.5px 主色）替代通用四角——品牌记忆点；8 手柄视觉 8px、命中区 12×12px；顶部居中尺寸徽标 `1280 × 720`。
- **悬浮工具条**（胶囊，高 52px，位于选区下方 16px，越界自动翻转到上方）：
  - 工具组：矩形/椭圆/箭头/画笔/马赛克/文字（右下角常显 `1–6` 快捷键角标）；
  - 属性组：颜色圆点（展开色板：10 常用色 + 自定义 `…`，记住最近使用色）+ 粗细（三线图标，展开预设 1/2/4/6/8px）；
  - 操作组（竖线分隔）：撤销、**录制（红圈点）**、贴图（中性）、**完成（绿色实底胶囊 + ✓，唯一强主操作）**。
  - 选中工具 = `accent-soft` 底 + accent 图标；悬浮 = `surface-3`。
- **编辑态提示条**：左上角半透明白胶囊，"调整选区 · 拖动移动 · 拉角缩放 · Enter 确认 · Esc 取消"，仅调整模式显示。

### 6.2 历史库
- 结构：标题栏（Windows 原生控件钮）→ 左侧栏 212px（全部/今天/昨天/本周/更早 + 已收藏 + 回收站，右侧计数胶囊）→ 主区（搜索框 + 排序/视图分段控件 + **立即截图**主按钮）→ 卡片网格（4 列，双击仍进大图查看器）→ 底部状态栏。
- 卡片：悬停上浮 3px + 阴影升级；悬浮层底部渐变上呈现 4 个 28px 操作钮：编辑/复制/贴图/删除（删除悬停变红）。
- 空状态：胶片隐喻插画 + "按 `Ctrl+Alt+A` 开始第一张截图"。
- 保留现有拖拽排序、日期归档能力，仅换视觉容器。

### 6.3 设置
- 结构：左侧分区导航（常规 / 截图与保存 / 热键 / 存储 / 关于）+ 右侧行式表单（标题+说明+控件右置），对齐 Windows 11 设置中心习惯。
- 控件规范：Switch 40×22；保存格式 JPG/PNG 分段选择器；热键录制框（点击进入监听态：蓝框+闪烁，冲突即时红字提示，Esc 取消）；保存路径行 + 浏览按钮；回收站天数步进器。
- 每个控件对应 `config.json` 现有字段：`hotkey / save_format / save_root / trash_days / auto_start / auto_copy`，无新增概念。

## 7. Tkinter 落地映射（避坑要点）

| 设计效果 | 实现方式 | 避坑 |
|---|---|---|
| 胶囊工具条 | 沿用 `editor.py` Canvas 圆角 + `-transparentcolor #010203` | 圆角半径 ≥18px 时 1px 色边不可见 |
| 窗口圆角/阴影 | `DwmSetWindowAttribute`（corner preference=33，backdrop type 可选 Mica） | Win10 无效则降级直角 + `#E3E6EA` 边框 |
| Switch/动画 | Canvas + `after(16ms)` 插值 | 高 DPI 必须声明 PerMonitorV2（沿用 dialogs.py 多屏方案） |
| 取景角标/手柄 | 遮罩 Canvas 画 L 形线段 | 命中区放大到 12×12，视觉 8px |
| 卡片悬停阴影 | PIL 预渲染阴影贴图；量大时降级为边框+变色 | 网格滚动时避免逐帧重绘 |
| 弹层 | 无边框 Toplevel + `overrideredirect` | `<FocusOut>` 自动关；Esc 先关弹层再取消截图 |

## 8. 实施建议（三步走）

1. **第一批（视觉层，低风险）**：统一 token 常量文件 `ui_theme.py`（颜色/圆角/阴影/字体映射），替换 editor 工具条与 settings 配色。
2. **第二批（组件层）**：Switch、分段选择器、热键录制框、Tooltip 升级为可复用组件。
3. **第三批（布局层）**：设置改分区导航、历史库改时间轴+网格、选区换取景角标。

Capture / Edit — 最高频路径

截图编辑器：取景框 + 快门工具条

延续现有「框选 → 调整选区 → 标注 → 完成」心智模型，仅做视觉与反馈升级：选区四角使用取景器角标（品牌记忆点），悬浮工具条保持胶囊形态并强化主操作「完成」的绿色识别。所有键位提示（左上角数字）与现有一致，零学习成本。

Gallery — 管理与回溯

历史库：日期轴 + 卡片流

将现有「无限画布 + 日期归档」重组为更易扫读的左侧时间轴 + 右侧卡片网格：高频操作（复制 / 编辑 / 贴图 / 删除）收敛到卡片悬浮层，双击仍进入大图查看器（习惯不变）。顶部搜索支持按文件名与备注检索。

Settings — 低频但关键

设置：左侧分区导航 + 行式表单

从单页长表单升级为「分区导航 + 行式设置」：每行 = 标题 + 说明 + 控件右置，符合 Windows 11 设置中心的心智习惯。热键录制框、格式分段选择器、开关等控件全部按本项目 config.json 字段一一对应，可直接映射实现。

Design Tokens — 落地基准

设计规范：SHUTTER 设计语言

一句话定位：「专业工具的克制 + 取景器的仪式感」。以 Windows 11 Fluent 为骨架，用取景框角标、快门蓝与胶片隐喻建立 ScreenSnap 自己的记忆点，同时保持与系统原生窗口一致的习惯感。

色彩系统

中性色统一偏冷灰蓝，避免纯黑纯白；语义色沿用现有代码中已出现的 绿(#07c160→精调)/红(#e5484d)，减少迁移成本。
